# UX Profile

Generado a partir de `docs/principios-ux.md`. Todas las skills de UI/UX de este proyecto leen este archivo antes de cambiar layout, textos o interacción.

## Aesthetic reference

- **Standard:** Custom
- **Notes:** Mercado Libre / PedidosYa en el flujo; sistema de diseño Eskemia v2 en lo visual (06/11/2026): Manrope como única familia, cifras tabulares, sin monoespaciada; color, radios y sombras solo por token con nombre por uso (`paquetes/tokens/tokens.json`).

## Banned anti-aesthetics

- Glassmorphism y `backdrop-filter` sin un borde de alto contraste
- Degradados decorativos y bordes de neón
- Más de un CTA primario por vista
- Ilustraciones caricaturescas en estados vacíos
- Modales centrados en móvil (usar bottom sheets)
- Spinners de pantalla completa
- Badges pastel flotantes para metadatos comunes
- Scrollbars anidadas e íconos decorativos dentro de inputs
- Hex, `rgb()`, radios o sombras escritos a mano (todo por token)
- Fuentes monoespaciadas o cualquier familia que no sea Manrope

## Accessibility target

- **Level:** WCAG 2.2 AA
- **Contrast:** Texto ≥ 4.5:1; texto grande y bordes ≥ 3:1. Estados nunca solo por color.
- **Touch / focus:** 44 × 44 px en escritorio, 48 × 48 px en móvil, 56 px en el kiosco de Recepción, separación mínima 8 px. Foco visible.

## Brand tone and microcopy voice

- **Voice:** Español rioplatense con voseo, directo, sin tecnicismos ("Confirmá el pedido").
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Botones con verbo; nunca "OK", "Enviar" o "Aceptar" sueltos.

## Icon library

- **Library:** Pendiente de definir (v2 pide íconos sólidos; hoy el código usa Lucide)
- **Package / path:** `lucide-react` (actual)
- **Notes:** Sólidos, dentro de un contenedor.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
